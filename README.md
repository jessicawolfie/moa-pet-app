Moa Pet App — app de rastreamento de saúde e rotina para pets, construído em Kotlin Multiplatform (KMP) com Compose Multiplatform para UI compartilhada entre Android e iOS. Arquitetura Clean Architecture com camadas de domain/data/presentation, Room KMP com BundledSQLiteDriver para persistência local, Koin para injeção de dependência multiplataforma e kotlinx-datetime para manipulação de datas cross-platform. Código plataforma-específico isolado via expect/actual. Projeto pessoal em desenvolvimento ativo.

EN
Moa Pet App — a pet health and routine tracking app built with Kotlin Multiplatform (KMP), using Compose Multiplatform for shared UI across Android and iOS. Follows Clean Architecture with domain/data/presentation layers, Room KMP with BundledSQLiteDriver for local persistence, Koin for multiplatform dependency injection, and kotlinx-datetime for cross-platform date handling. Platform-specific code isolated via expect/actual. Personal project under active development.
